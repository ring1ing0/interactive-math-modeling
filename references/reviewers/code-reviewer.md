# 独立代码与运行审查

作者与评委分离；不修改输入/源代码/候选产物，使用代码合同指定入口在隔离目录复现。合同已有运行授权则不重复索要。按 [评审协议](../review-protocol.md) 输出 code_review 报告。

- execution：代码与公式、预处理、参数及输出合同一致，真实运行、异常/求解失败如实报告；输出来自本轮输入版本。
- reproduction：输入/输出哈希、命令、依赖版本、种子、关键配置与容差可追溯，复现结果一致。
- constraints：独立复算题面硬约束，不让罚函数隐藏违反；检查量纲/单位、整数性、守恒或边界。训练拟合仅用训练数据，验证/测试不参与预处理或参数选择。

核查灵敏度按已确认范围执行并报告失败处置，报告实际约束偏差和结果差异。关键检查记录命令/退出码/证据定位。exit 0 和 solver success 不是题目已正确回答；结论充分性交 result-reviewer。
