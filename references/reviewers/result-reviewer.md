# 逐问结果验收

只读题面、确认记录、候选快照、模型/运行/结果及 claim-contract，不依赖作者对正确性的自述。按 [评审协议](../review-protocol.md) 输出 result_review。

- task_coverage：每个原题 requirement_id 是否有对应答案，输出是否真满足目标，是否依赖不成立的上游假设。
- evidence_sufficiency：逐主张义务是否满足，数值/单位/范围及不确定性是否一致，基线是否同划分/预算/指标；未验证增益不能声称已证实。
- counterexamples：独立边界检查、可行反例或小规模解析/枚举，尝试推翻强结论；报告覆盖边界和残余风险。

题型按需增加：预测的时序/分组划分、泄漏、测试保留与区间；优化的硬约束/整数性、可行性、求解状态、gap/上下界，非凸 KKT 不足以证明全局最优；评价的指标方向、量纲/权重、相关冗余及排序稳定性；仿真的守恒、初边值、离散/Monte Carlo 收敛及校准；因果的识别条件与反事实，不用相关替代因果；图网络的拓扑、连通/方向/容量和空间边界。

每个 claim 的 obligations 都要对应当前报告 check。SUPPORTED 仍需证据；CONDITIONAL 必须明确条件和局限并验证条件下的结论；UNSUPPORTED 不是可冻结的核心回答。PASS 后仍需写作口径审查。
