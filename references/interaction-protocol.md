# 交互协议

每轮说明当前节点、必要证据、一个实际待决定事项和下一步；历史进文件。自动验收节点无待决定事项时只报告结果，不机械要求用户确认。

## 人决策点

S2 总纲；S3-DONE 约束审计完成后暂停；L1 需要文献时筛选；Qn-INIT-D1 问题范围/视觉合同；Qn.uK-D1 口径；Qn.uK-D2 算法；Qn-PARAM-D1 参数/验证范围；Qn-CHART-D1 图表；Qn-CODE-CONTRACT 执行范围；F1 正式图表新计划/取舍。

Qn-PLAN-DONE、代码/结果/口径验收和全题评委是自动节点。W1 由实际外部文稿触发，不要求没有文稿的用户等待。明示的“按这个范围执行/你决定”可作为该范围授权并记录；沉默和模糊回应不能。

## 逐 unit

D1 只讨论目标、信息可用性、依赖、数据子集、局部约束与预处理方向，并标证据类型。D1 后才讨论算法/强基线、适配条件、验证、风险和成本。候选数量由真实权衡决定，库中出现不能作为推荐理由。D2 后轻量检查目标/约束是否被算法改变，有冲突重新确认相关口径，不自行改用户决定。

全部 units 确认后统一方案审查，不把每个 unit 变为固定多评委审查。审查及已授权程序修复可在当前节点内完成；改变模型方向或口径回到对应人决策点。

## 逐问收尾

结果验收后展示：回答的题目要求、关键结果、证据来源、适用边界、写作可说、写作不可说。显示 PASS/FAIL/BLOCKED 与实质未决项，不能只给“已完成”。口径交接卡逐 unit 覆盖，整问通过才冻结进入下一问。

## 图表与正文

参数/验证设计先于最终图表确认；图表逐张讨论论证问题、数据/字段/单位、变换/不确定性、颜色语义、输出验收。讨论期按用户请求或确有证据需求生成诊断图；不自动成为正式图。

全题评委直接给建模获奖潜力、比较依据和未评部分；正文没提供不推断表达或版式质量。正文返回后仅检查事实与结论一致性，给定位清单和局部修改方向。

决定、授权、修正、版本失效、审查和恢复均追加事件，保存证据引用。不反复读取无关历史。
